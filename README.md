## 槓桿 ↔ 現金 調整情境

| 情境 | 槓桿目標% | 現金目標% | 年化波動預估 |
|------|---------|---------|------------|
| 🔵 保守（退休前） | 8% | 10% | 20~25% ✓ |
| 🟢 平衡（當前建議） | 12% | 8% | 25~32% |
| 🟡 積極（多頭持續） | 18% | 5% | 32~40% ⚠️ |

**VIX 觸發原則：**
- VIX < 15 → 維持或小幅增槓桿
- VIX 15~25 → 維持，不加碼
- VIX > 25 → 分批減碼至10%以下
- VIX > 35 → 快速降至5%以下
