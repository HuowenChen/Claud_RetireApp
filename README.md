## 持股 Bar Chart 規格

四個市場（台股/美股/日股/基金）各自一張橫向 Bar Chart：

- **依市值由大到小排序**，最多顯示15筆，其餘合入「其他X檔」
- **顏色**依類型區分：個股#E24B4A / ETF#378ADD / 槓桿#EF9F27 / 主動ETF#1D9E75 / 現金替代#7F77DD
- **標籤顯示**（`afterDatasetsDraw` plugin）：
  - Bar 夠長 → 標籤在 Bar 右端**內側**，白色字（`XX萬 (YY%)`）
  - Bar 較短 → 標籤在 Bar 右端**外側**，灰色字
- **x 軸右邊留白**（`padding.right: 110`，`max: maxVal × 1.45`）確保標籤不被截斷
- Hover tooltip 同時顯示萬元和百分比

```html
<!-- Chart.js CDN 獨立 script -->
<script src="https://cdnjs.cloudflare.com/.../chart.umd.js"></script>

<!-- 自訂 JS 必須在新的 script 標籤內 -->
<script>
const DARK = ...
function buildHBar(...){ ... }
...
</script>
```
> ⚠️ 兩者不能合併，否則瀏覽器把自訂 JS 當成 src 屬性，所有圖表失效。

### Bar Chart 百分比標籤 Plugin
```javascript
const labelPlugin = {
  id: 'hbarLabel',
  afterDatasetsDraw(chart) {
    chart.data.datasets[0].data.forEach((val, i) => {
      const bar = chart.getDatasetMeta(0).data[i];
      const txt = `${val}萬 (${pcts[i]}%)`;
      // Bar 夠長 → 標籤放內側（白字）
      // Bar 較短 → 標籤放外側（灰字）
    });
  }
};
// 套用：new Chart(ctx, { plugins: [labelPlugin], ... })
// x 軸需設 max: maxVal * 1.45 確保外側標籤不被截斷
```
